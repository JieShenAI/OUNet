启动后什么时候检测网络？

立即执行第一轮，不等待检查间隔。外网可用时读取在线会话；检测到需要认证时，使用已选 Wi-Fi 与校园网账号尝试恢复，复通后刷新在线信息。

为什么外网可用，但在线会话暂不可用？

网络连通性与校园网门户信息分别展示。门户读取失败时，有旧数据则注明更新时间和“旧数据”；没有可用数据时显示“暂不可用”。源 IP 等字段以门户实际返回值为准。

什么时候会计入一次网络恢复？

同一次中断在助手完成恢复并验证外网可用后计入一次。普通在线检查、失败请求、重复回调均不增加计数。记录跟随当前 Windows 启动周期，重启软件后保留。

请求暂停后怎样恢复？

连续三个 HTTP 请求失败后停止所有自动网络请求。可在连接概览中手动重试；成功请求将连续失败数清零。等待、切换页面或切换守护开关都不会解除暂停。

检查间隔太短，会同时发起多轮请求吗？

每轮完成后，再等待设定秒数。若最近一轮耗时超过设置间隔，会显示间隔过小提示。任何时刻只有一轮执行，重复触发被合并，无历史触发补发。

如何查看所有更新状态？

使用窗口上方的“演示场景”。“请求失败 +1”可逐次查看第一次、第二次与第三次失败；“1 秒间隔”演示 3.2 秒请求的串行调度；重启软件和重启电脑演示恢复记录的生命周期。

此原型的所有网络行为均为本页定时模拟。账号和地址为虚构数据；IPv4 使用 192.0.2.0/24，IPv6 使用 2001:db8::/32 文档地址。门户标识用于说明信息来源。
