## 打开原型

用 Edge 或 Chrome 打开本目录的 [`index.html`](index.html)。全部字体使用系统字体，图片、样式和脚本均在本地，无需安装依赖，也不依赖外网加载资源。

页面顶部是设计演示工具，不属于正式产品界面：

- **正常联网**：点击“检查并连接”，显示外网通过且没有提交认证。
- **断网 / 认证失败**：每点击一次模拟一轮失败；第三轮后停止认证。保护期间检查只检测外网，开关守护不会解除保护。
- **断网 / 认证恢复**：模拟检查、校园网认证、外网复查和恢复成功。
- **三轮失败保护**：直接查看保护状态和手动重置说明。“恢复外网”模拟环境变化，检查通过后才清除保护。
- **其他 Wi-Fi / 权限异常 / 手动暂停**：查看相应的原因、主要动作和帮助。
- **首次设置**：体验目标 Wi-Fi、演示账号、旧任务迁移和登录后自启四步流程。取消旧任务迁移后，新守护保持暂停。
- **安装流程**：体验按当前用户安装、准备组件、完成及进入首次设置。这里不会真正安装任何软件。

左侧五个页面、首页开关、设置开关、失败保护对话框、账号保存演示、日志筛选和导出演示记录均可操作。右上角最小化、关闭和底部“托盘预览”可体验系统托盘菜单；最大化按钮说明建议尺寸。

**请勿在原型输入真实账号密码。** 原型只有虚构数据，不调用认证接口、不读取真实配置、不持久保存输入、不更改自启或任务计划。刷新页面会还原演示场景。唯一主动生成的文件是点击“导出演示记录”下载的模拟日志。

## 验证范围

已进行 JavaScript 语法检查和本地浏览器交互检查。核对联网状态、三轮失败保护、保护期间只检查、守护开关保留保护、手动重置、模拟恢复、导航、安装与首次设置、托盘菜单等流程。原型的模拟检查不等于真实校园网断网认证测试。

真正的桌面版应按产品规划分阶段实现并验证：先将认证逻辑拆成可复用核心，再接入桌面 UI、用户级状态与凭据存储、旧任务迁移，最后打包安装器。现有脚本与 Android 项目保持各自的运行方式。
