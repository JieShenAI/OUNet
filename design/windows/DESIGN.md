# 海大网络助手 · Windows 界面设计规范

> **历史版本：** 本文对应 v0.1。2026-10-22 的 desktop 更新设计以 [v0.2 方案](../../docs/WINDOWS_DESKTOP_V0_2_PLAN.md)和[新版原型](desktop-v0.2.html)为准，覆盖本文的五页导航、常驻保护卡、单账号与分钟级间隔等约定。

2026-10-22 · v0.1 · 对应本目录交互原型

## 1. 设计方向

主题为“海蓝与轻盈的秩序”。用户打开软件时应先看懂网络是否可用、守护是否运行、是否触发保护。平时将窗口收起，软件留在托盘，不需要停留在一个持续刷新的仪表盘。

产品工作名称“海大网络助手”，副名 OUC Network Assistant。学校校徽和中英文校名使用官网下载的白色原始组合；应用图标另用原创波浪与 Wi-Fi 组合，开始菜单、任务栏、托盘均使用应用自身图标。侧栏底部明确“个人校园网络工具 · 非学校官方软件”。

不以学校新闻、账户余额、网络速率、虚构“节省请求数”等填充首页。校园湖景仅在侧栏形成轻量文化背景，连接状态始终是视觉中心。

## 2. 色彩

官方标准色已经从学校标准色图示核实，来源见 [`SOURCES.md`](SOURCES.md)。衍生色服务于桌面界面，不标为官方色。

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 主操作 / 选中 / 应用图标底色 | `#004098` | 官方“海大海蓝” |
| 校园色参考 / 海洋细节 | `#00A0E9` | 官方“海大天蓝”，控制用量 |
| 校园色参考 | `#C81528` | 官方“海大红”，本原型仅少量用于关闭悬停 |
| 侧栏 | `#102C50` | 设计衍生深蓝，托住原始白色标识 |
| 正文 | `#182C47` | 核心文字 |
| 次要说明 | `#63758B` | 说明、网络摘要 |
| 页面底色 | `#F5F7FA` | 中性浅灰 |
| 卡片 | `#FFFFFF` | 安静的主内容表面 |
| 细边框 | `#E6EBF1` | 以边框和间距区分层次 |
| 外网可用 | `#168063` / `#E8F5EF` | 绿字与浅绿背景，同时提供文字及图标 |
| 需要关注 / 保护暂停 | `#986114` / `#FFF4DE` | 琥珀色，不把保护暂停渲染为紧急故障 |

主按钮保持实色海蓝。只有连接图形和背景波浪使用很轻的渐变与透明度；避免大面积炫光、闪烁或持续旋转。

## 3. 布局与字体

- 原型参考窗口：1180 × 814 像素；侧栏 207 像素，标题栏 36 像素，底部状态栏 29 像素。
- 内容四周约 24–32 像素；卡片间距 15 像素；圆角主要为 11–14 像素，按钮 6 像素。
- 首页由标题、连接主卡、守护与保护双卡、网络摘要、最近活动组成。
- 首页主按钮只保留一个。次要动作使用文字链接，不与“检查并连接”争夺注意力。
- 字体优先 Segoe UI Variable / Segoe UI，中文回退 Microsoft YaHei UI；不下载字体。大状态标题约 32 像素，页面标题约 25 像素。
- 原型为紧凑视觉示意。真实 Qt/QML 版使用逻辑像素，正文建议 13–14、说明 12–13，不能直接照搬原型中 8–10 像素的微型辅助字。
- 原生实现适配 100%、125%、150%、200% DPI 和系统字号；尺寸不足时内容区纵向滚动，导航、标题栏和托盘入口保持可用。

原型为了方便在窄浏览器审阅，提供精简侧栏响应式布局；这不代表移动端产品设计，也不是 Windows 程序最小尺寸承诺。

## 4. 页面与组件

### 连接概览

主卡只回答三个问题：当前状态、原因、下一步。右侧连接图形为辅助元素，不能独立承载状态。外网可用时明确说明“无需提交校园网认证”，避免用户担心后台反复登录。

守护卡与保护卡分开。用户开启自动守护时，认证仍可能因失败保护暂停；首页与托盘必须同时说明。进度“0 / 3 轮”是认证轮次，不是请求数；不使用让用户以为等待十分钟就能解除的倒计时。

### 账号与网络

账号、密码、目标 Wi-Fi 集中管理。密码默认隐藏，显示按钮有可访问名称。正式版按当前用户加密保存，界面只展示“已保存”，不要把解密后的密码预填至可导出的配置页。保存设置不能隐式重置失败预算。

目标 Wi-Fi 选择已保存配置；Wi-Fi 密码仍交由 Windows 管理。自动切换到目标网络默认关闭，用户主动切换前说明会断开当前连接。

### 连接记录

用用户能理解的结果描述：外网检查通过、认证后复查失败、保护暂停、配置变更。不要把完整请求 URL、Portal 响应和异常堆栈直接放进主流程。

记录可按成功 / 需要关注 / 信息筛选；导出前显示脱敏范围。原型只下载模拟记录，真实导出需去除账号、密码、令牌及敏感设备信息。

### 偏好设置

按启动与窗口、检查与提醒、失败保护三组排列。保护阈值在首版固定展示，不做成鼓励增加重试次数的普通滑块。正式版设置保存后显示实际生效状态，失败时恢复开关并给出原因，不能只出现“保存成功”。

### 帮助与关于

优先解释已有网络不登录、失败保护解除、旧任务迁移、锁屏与睡眠行为。产品版本、独立工具身份和学校素材来源集中展示，不在每张卡片重复技术背景。

## 5. 状态与动作约定

| 场景 | 主要标题 | 主操作 | 约束 |
| --- | --- | --- | --- |
| 外网通过 | 网络已连接 | 检查并连接 | 仍先检测，有网不认证 |
| 外网断开 | 网络暂时断开 | 检查并连接 | 仅目标网络上认证，受统一预算约束 |
| 检查中 | 正在检查连接… | 禁用 | 所有入口串行，重置入口同样禁用 |
| 认证中 | 正在恢复校园网… | 禁用 | 认证后必须复查，未复查通过不能显示已连接 |
| 保护触发 | 认证已保护性暂停 | 只检查外网 | 外网恢复或明确手动重置才能清除 |
| 用户暂停 | 自动守护已暂停 | 检查并连接 | 手动检查仍遵守保护，重新开启不清除预算 |
| 当前非目标 Wi-Fi | 当前使用其他 Wi-Fi | 连接目标 Wi-Fi | 确认后切换，网络名随配置变化 |
| 无法读取 Wi-Fi | 需要检查 Wi-Fi 权限 | 查看处理方法 | 不默认要求管理员权限 |
| 旧入口未处理 | 旧任务等待处理 | 处理旧任务 | 新守护保持暂停，避免并行入口 |

原型顶部场景切换是设计审阅工具，会重置模拟场景；正式软件没有此工具。正式版不能因页面切换、重开窗口、重启或升级而重置失败状态。

## 6. 托盘、通知与窗口关闭

默认关闭主窗口只收起到托盘。菜单为打开主界面、检查并连接、暂停 / 恢复自动守护、退出。托盘的“检查”与首页共用同一个控制器，不创建第二个认证任务。

第一次收起时给一次轻量说明，之后不重复提醒。通知只用于网络恢复、首次触发保护、配置或权限需要处理；持续联网、每轮探测、持续相同错误不弹通知。

用户退出会停止守护、保存状态并释放互斥锁。登录后自启与“开机未登录即运行”不同；锁屏继续，睡眠期间不承诺检测，唤醒后合并事件检查。

## 7. 首次设置与安装

安装按当前用户完成，无需安装 Python。原型三步为准备、安装、完成；完成后进入首次设置，不默认开启系统自启。

首次设置四步为目标 Wi-Fi、校园网账号、旧脚本迁移、运行偏好。导入旧任务必须展示匹配路径、任务名及处理范围；未处理时只保存配置，不启用新守护。失败状态与配置一起迁移。

真实安装器还需明确版本、发布者、许可说明、目标位置、卸载入口；公开分发前完成依赖许可与签名方案。原型不模拟接受真实许可、不制作虚构证书或伪造发布者。

## 8. 无障碍与动效

- 颜色之外同时提供状态文字、图标及原因。
- 所有按钮、开关、输入框可用键盘操作，开关暴露 `aria-checked`，当前导航暴露 `aria-current`。
- 对话框提供明确标题和取消路径；关闭后恢复触发元素焦点。真实原生窗口需支持屏幕阅读器。
- 不用悬停作为唯一发现路径，不靠极细文字承载关键结论。
- 动效仅用于页面进入、检查和安装过程；尊重减少动态效果偏好。

## 9. 实现交接

设计采用 Windows 桌面习惯及清晰的导航，推荐后续用 PySide6 + Qt Quick/QML 还原。HTML 仅用于快速审阅，不要求把浏览器运行时一起打进安装器。

界面订阅结构化状态，不解析日志字符串猜测状态。联网检查、Wi-Fi、认证、预算、凭据和迁移均由业务控制器统一管理；具体接口与验收见 [`Windows 产品规划`](../../docs/WINDOWS_PRODUCT_PLAN.md)。
