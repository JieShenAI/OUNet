OUNet · Windows 个人版

这是个人开发的校园网络辅助工具，非中国海洋大学官方软件。

程序启动后优先检查外网；验证通过就结束，不自动查询 XHA 或提交校园网认证。
使用当前已连接的 IPv4 网络接口，不扫描或切换 Wi-Fi。支持多账号与最低 0.3 秒的小数间隔，请求始终串行执行，旧间隔升级后保留。
按实际 HTTP 请求计数；连续 3 次请求失败后停止全部自动网络请求，等待手动重试。等待或重开软件不会解除暂停。

安装包不包含个人账号密码。凭据由 Windows 当前用户加密保存；明确密码错误会提示并停止该组凭据的自动 XHA 请求。概览的身份信息由用户主动刷新，恢复统计按本次电脑开机记录，请求统计按进程记录。

如果之前使用过 auto_login_ouc 脚本或任务计划，请从偏好设置导入原 .env 并完成迁移，以免多个入口同时运行。旧版暂停继续保留，原 .env 不会自动删除。

登录后自启由你在软件中选择。关闭窗口默认收起到系统托盘；完全停止请从托盘选择“退出”。

本版本尚未通过实际断网、重启和睡眠恢复的全部用户环境验证。未代码签名；第三方许可随软件提供。
