# OUNet Windows 0.3.4

Windows 10 1809+ / Windows 11 x64。

- 临时故障三次后暂时暂停，按15秒、30秒、1分钟、2分钟、5分钟自动复检，上限后继续每5分钟复检，恢复后继续守护。
- 保留复检定时器，路由器恢复即使没有网络变化事件也可重新检查；重复网络事件不会无限触发提前重试。
- 分开记录外网探测、XHA传输、认证结果和GitHub更新故障，避免无关请求影响认证保护。
- 冷却跨重启保留，原普通三次失败暂停迁移为首轮15秒冷却。明确密码错误、用户主动关闭守护、旧入口安全暂停和本地状态异常保持独立处理。
- 包含账号输入不中断与按钮闪烁修复，后台复检不锁定账号编辑器。

安装包 `OUNet-0.3.4-Setup-x64.exe`；完整免安装包 `OUNet-0.3.4-Windows-x64-portable.zip`。升级前请从托盘完全退出旧版。沿用原AppId、加密方式和数据目录，提供SHA-256校验文件。
