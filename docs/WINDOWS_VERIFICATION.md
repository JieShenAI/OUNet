# Windows 0.2.0 实现与验证记录

> 本文为 v0.2 历史记录。最新 0.3.0 的实际界面、测试与安装包见 [v0.3 实施与验证](WINDOWS_V0_3_VERIFICATION.md)。

日期：2026-10-22。当前交付为 0.2.0 测试版，保留真实断网、自启和电源状态的环境验收边界。

## 已实现

按 [v0.2 更新规划](WINDOWS_DESKTOP_V0_2_PLAN.md)完成实际 desktop 代码：启动优先探测、六字段校园会话、Wi-Fi 下拉与多账号、秒级串行调度、按实际 HTTP 的三连败暂停、本次系统开机恢复台账，以及删除连接记录页和常驻保护卡。Android 和未接管独立 CLI 保持原行为。

## 已执行的检查

| 检查 | 结果与范围 |
| --- | --- |
| Desktop 单元/控制器 | **54 项通过**。所有网络/认证测试使用虚构账号和模拟响应，不提交真实密码 |

| 恢复台账 | 故障 ID 去重、外部自行恢复不计数，同次 boot 重开对象保留，新 boot 切换记录；信息查询失败不撤销已验证恢复 |
| 门户字段只读实测 | 新 `PortalClient` 成功查询实际在线状态和记录，匹配当前设备并返回六个展示字段，无登录/注销/绑定/解绑；摘要不保存实际账号地址 |
