## 下载与升级

推荐下载 `OUNet-0.3.1-Setup-x64.exe`。升级前从托盘完全退出 OUNet，再运行安装器覆盖安装；保留原 AppId、用户数据目录、账号、设置和既有暂停状态。

免安装用户下载 `OUNet-0.3.1-Windows-x64-portable.zip`，解压后保留完整 `OUNet/` 目录并运行 `OUNet.exe`。退出旧程序后更换程序目录；不要只复制 EXE。

本版本未做 Windows 代码签名；同目录提供 SHA-256。应用检查并展示发布元数据，浏览器下载后由用户运行安装器，不自动执行安装。

检查更新默认查找本仓库 Windows 正式版；草稿、预发布及 Android APK 不进入默认更新。实验性网络环境、真实睡眠唤醒和系统版本覆盖范围以仓库验证记录为准。
