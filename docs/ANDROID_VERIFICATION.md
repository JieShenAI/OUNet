## 已完成的升级

- **启动检测**：首屏立即显示“正在检测”，`onResume` 提交异步检查；未配账号、未开启监测和没有 SSID 授权时也显示基础网络状态。首次检测的实际耗时目标仍需在设备测量。
- **真实 Wi-Fi**：当前连接与目标分开显示；前台/服务均可注册带位置信息的网络观察，旧系统单连接回退；双 Wi-Fi 按明确目标识别，同名双连接或名称不可见时不猜测。
- **附近扫描**：进入目标设置时请求一次扫描，展示信号和系统结果年龄；接收扫描更新，区分缓存、失败与节流；下拉选择或使用当前名称后，仍需明确“设为目标”。周期检测不会触发扫描。
- **多账号**：稳定 ID、单独密文与 IV、备注及凭据版本；首页脱敏下拉选择；新增、编辑、删除与选用；新账号密码必填、编辑留空只沿用自己的密码；删除当前账号关闭监测并要求重选。
- **迁移**：旧密钥/密码密文/IV 延用，旧单账号迁移到固定 ID；分钟一次性乘 60；新配置与版本标记同次提交；旧加密字段、目标、开关与全局失败保护保留。
- **秒级调度**：10–3600 整数秒，默认 120；快捷填值、明确保存；短轮次按开始时点排程，超期不积压；原固定 30 秒心跳与 60 秒检测门槛移除。
- **认证保护**：保留所有账号共用的三轮暂停；持久化独立 60 秒认证节流；切换、编辑、新增/删除、迁移和改间隔不能重置预算；手动重置也不绕过节流。
- **任务一致性**：单工作线程、最多一个待替换任务；同一配置下触发合并；配置快照和取消标记在请求阶段复核，旧结果失效。已经交给网络栈的请求不保证撤回。
- **品牌适配**：使用 Android 公共接口；小米/Redmi、iQOO、vivo、OPPO 及其它系统的指导可自动选择和手动切换；公开系统设置入口带失败回退；厂商白名单明确显示无法自动确认。
- **构建交付**：版本升级；本地和 CI 从 APK 元数据生成版本化名称及 SHA-256；保留原包名、签名、禁用备份、HTTPS 校验和 Wi-Fi 绑定请求。

## 试装验收步骤

1. 保存原 APK，直接覆盖安装 1.1.0，不先卸载。核对原账号、目标、开关、120 秒换算和已有暂停状态；不要为测试主动提交错误密码。
2. 关闭监测，重新打开应用，查看本机网络及 Wi-Fi 状态；未填账号时也应检测。进入目标设置，核对系统 Wi-Fi 名称，扫描结果不可自动保存为目标。
3. 保存三个可用账号并下拉切换；确认选中项重启后保留；编辑留空密码不影响其它账号；删除当前账号关闭监测并要求重选。
4. 已在线时“检查并连接”不提交认证。保持移动数据打开，在目标 Wi-Fi 确实需要认证时验证恢复；移动数据成功不能清零校园 Wi-Fi 的保护。
5. 亮屏时分别设置 10/30/120 秒并保存，观察实际上次时间；长请求不得积压。账号切换、目标变更和间隔保存不能立即额外提交登录。
6. 按对应品牌设置后台能力，验证锁屏、长时间后台、Wi-Fi 切换、重启后首次解锁与更新恢复；记录实际检查时间和延迟，不以深度休眠严格准点作为承诺。

遇到问题优先查看本机运行记录，不反复重置保护。记录机型、地区、完整 ROM/Android 版本、APK 版本、权限及后台设置，再填写实际结果。

## 执行限制与阶段结论

M1–M3 工程实现完成；M4 的本地单元测试、Lint、构建及元数据检查完成，设备验收待进行；M5 已提供同签名的本地试装包与校验文件，尚不宣称四品牌全面验收或公开稳定发布。

8 秒探测与 60 秒整轮预算在网络步骤和读取过程中核验，并有取消机制；系统 DNS/native I/O 可能无法立即中断，实际取消时延和首次启动的1秒发起目标仍需测量。单线程及有界待执行队列用于防止请求堆积。
