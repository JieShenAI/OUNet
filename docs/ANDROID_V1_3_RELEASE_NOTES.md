# 海大网络助手 Android 1.3.0

- 顶部仅展示实际Wi-Fi名称，取消扫描、目标SSID和切换功能。
- 启动先验证XHA校园服务，再检测外网并按需认证；非校园网显示红色禁入图标。
- 本地评估默认1秒，支持0.3–3600秒；公共探测轮换、缓存和独立限流。
- 增加当前在线账号的设备列表，支持分页及完整性提示。
- 恢复记录底部显示本次启动和最近60秒的XHA请求尝试数量。
- 设置增加离线介绍、数据使用、JShen版权说明及GitHub Android更新检查。
- 保留原正式包名、签名、Keystore和全局认证频控；不需要先卸载旧版。

免费软件，供学习交流与使用。项目自有代码采用 MIT 许可证。

校园服务可达性是本APP的识别判据，不能证明网络的地理归属。0.3秒是本地评估间隔，HTTP实际频率受预算及系统调度限制。真实校园认证、设备分页和小米/iQOO/vivo/OPPO后台行为仍需真机验收；本包供试装验证，不能把本地自动测试视为真机通过。

更新方法：下载同签名正式APK并确认覆盖安装，保留原账号与设置。GitHub检查更新需要发布android-v1.3.0标签及本次构建生成的android-update.json附件；源码提交不会自动更新手机上的应用。
