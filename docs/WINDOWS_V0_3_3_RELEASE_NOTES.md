# OUNet Windows 0.3.3

Windows 10 1809+ / Windows 11 x64。

- 修复底部“自动检测运行中”与“正在处理，请等待本轮完成”切换时，账号管理输入框无法持续输入的问题。
- 后台检测期间可以打开添加账号、切换本机账号详情，连续填写账号、密码和备注；保留输入焦点、光标与中文输入法组合文字。
- 实际配置写入期间仍保护编辑器，保存、删除及认证仍按原有规则串行执行。保存按钮在网络任务完成后可用。
- 包含 0.3.2 的按钮闪烁与账号列表焦点修复。

安装版：`OUNet-0.3.3-Setup-x64.exe`；免安装版：`OUNet-0.3.3-Windows-x64-portable.zip`。升级前从托盘完全退出旧版，再运行安装器覆盖安装。保留原 AppId、账号加密方式和数据目录。

本版本未做 Windows 代码签名，提供 SHA-256 文件。[验证记录](https://github.com/JieShenAI/OUNet/blob/main/docs/WINDOWS_V0_3_3_VERIFICATION.md)。
