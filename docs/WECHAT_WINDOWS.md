# 给电脑配一个校园网助手：OUNet Windows，让连接状态一目了然

**公众号摘要：** OUNet Windows 面向中国海洋大学校园网，提供联网检测、按需认证、多账号管理、在线设备查看与托盘运行。图形界面，无需安装 Python，也能用上校园网连接助手。

---

查资料、写论文、下载文件时，电脑明明连着校园 Wi-Fi，却突然打不开网页。是需要重新认证，还是网络本身出了问题？

**OUNet Windows** 希望帮你更快看清状态，减少反复打开认证页面、输入账号密码的操作。

这是一款面向中国海洋大学校园网的桌面连接助手，支持 **Windows 10 1809 及以上版本、Windows 11 的 x64 电脑**。它提供图形界面，运行打包版本无需另外安装 Python。

## 能上网时少打扰，需要认证时再出手

开启自动监测后，OUNet 会先验证外网连通性。外网可用时，本轮检查立即结束，不自动读取校园认证平台，也不重复提交密码。

外网不可用时，软件会进一步识别校园认证环境；确认需要登录、且配置与保护状态允许时，再使用选中的账号尝试认证。

你也可以随时点击 **“重新检测并连接”** 主动检查。已经在线时不会重复登录；明确未登录时，一次操作最多提交一次认证。

软件不会替你扫描或切换 Wi-Fi。先在 Windows 网络设置中连好校园网络，接下来的检测与认证再交给 OUNet。

## 账号管理清楚，当前身份也清楚

软件支持保存多个账号、添加备注，并选择 **“下次认证使用账号”**。编辑已保存账号时，密码留空即可保留原密码。

本地选中的账号和学校平台当前在线的账号会分开展示。**切换本地账号不会自动注销现有校园网会话。** 这样，你能知道下次准备用谁登录，也能看清当前实际是谁在线。

如果学校平台明确提示密码错误，软件会持续展示问题，并停止这组凭据的自动校园网请求，方便你先更正密码。

## 连接详情与在线设备，按需刷新查看

点击 **“刷新信息”**，可以只读查询学校平台返回的在线账号、上线时间、IPv4、IPv6、MAC 和移动端标识。这项操作不会提交密码。

通过 **“查看在线设备”**，还可以查看当前实际在线账号下的平台可见记录，并按需加载更多。

学校没有提供的字段不会推测；上次读取的会话信息会标注时间，帮助你区分历史记录与当前状态。设备查询只读展示，不提供强制下线操作。

## 留在托盘，按自己的节奏监测

关闭窗口后，OUNet 可以继续留在系统托盘；是否随 Windows 登录后启动，由你选择。需要完全停止时，从托盘退出即可。

自动监测默认间隔为 **1 秒**，支持自定义，最低 **0.3 秒**。每轮完成后再等待设定时间，不会因为上一轮耗时较长而堆积、并发补发任务。

发生异常时也有明确的暂停机制：实际网络请求连续三次失败后，软件会暂停本轮剩余及后续自动请求。检查原因后，可通过 **“手动重试”** 发起一次校园平台只读检查，通过校验后再恢复相应流程。

概览中的恢复记录帮助你回顾连接变化；帮助页可查看诊断记录，并导出脱敏文件，便于排查问题与反馈。

## 本机加密保存，源码公开可查

OUNet 没有广告、遥测或自建云账号。已保存密码使用 Windows 当前用户的 DPAPI 加密保护，账号、设置和诊断记录存放在本机。

执行校园网认证时，必要的凭据会发送给学校认证平台；公共联网检测与 GitHub 更新查询访问各自服务，不附带校园网账号和密码。

软件源码公开，也提供作者联系与问题反馈入口。

## 如何获取与开始使用

版本公开后，可前往 [OUNet GitHub Releases 下载页](https://github.com/JieShenAI/OUNet/releases)，选择 Windows 正式版本。本文对应的准备版本为 **0.3.1**，实际可用版本以下载页为准。

提供两种使用方式：

- **安装版：** `OUNet-0.3.1-Setup-x64.exe`，适合日常安装使用。
- **免安装版：** `OUNet-0.3.1-Windows-x64-portable.zip`，解压后保留完整文件夹，运行其中的 `OUNet.exe`。

首次使用时：

1. 在 Windows 中连接校园网络。
2. 打开“账号管理”，添加自己的校园网账号与密码。
3. 确认没有其他自动认证程序同时运行；旧脚本用户按引导完成接管。
4. 选择下次认证使用的账号，主动检测，或开启自动监测。

升级前先从托盘完全退出旧版，再按照发布说明覆盖安装。应用内支持手动检查本平台正式版更新，下载和运行安装器由你确认。

当前准备版本尚未进行 Windows 代码签名，发布附件提供 SHA-256，下载时请核对项目来源与对应文件。
