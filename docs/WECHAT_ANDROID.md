# 校园 Wi-Fi 连上了，却上不了网？试试 OUNet 安卓校园网助手

**公众号摘要：** 面向中国海洋大学校园网，OUNet 安卓版把联网检测、按需认证、多账号管理和在线设备查看放进一个应用。免费开源，无广告，让日常连接少一点重复操作。

---

手机已经连上校园 Wi-Fi，网页却迟迟打不开；退出认证页面后，下一次断网又得重新找入口、输密码。

如果你也遇到过这些情况，可以了解一下 **OUNet 安卓版**。

这是一款面向中国海洋大学校园网的连接助手，支持 **Android 9 及以上系统**。先连接校园 Wi-Fi、保存自己的校园网账号，OUNet 就能帮你检查外网是否可用，并在需要时尝试认证。

## 先看能不能上网，再决定要不要登录

OUNet 会先检测实际 Wi-Fi 的外网连通性。已经能上网时，本轮检测就会结束，不再自动查询校园认证平台，也不重复提交密码。

如果外网不可用，它会进一步识别校园网认证环境；只有明确未登录、且已经选好账号时，才尝试认证。遇到“校园账号已在线，但外网仍异常”的情况，也不会一遍遍重交密码。

你也可以点击 **“重新检测并连接”**，主动检查当前状态，并在需要时发起连接。

## 多账号保存，日常切换更方便

在“账号管理”中，你可以添加、编辑和删除本机保存的账号，选择下一次认证使用哪一个。

**本地选中的账号与校园网当前在线的账号会分别展示。** 切换本地账号后，如果网络已经可用，应用不会强制退出现有会话再登录。

编辑账号时，密码留空会保留原密码；学校认证平台明确返回密码错误后，应用会给出提示，并停止使用这组错误凭据自动请求，方便你先更正信息。

## 当前谁在线、设备信息是什么，一处查看

需要了解连接详情时，可以主动刷新校园网信息，查看平台实际返回的在线账号、上线时间、IPv4、IPv6、MAC 和移动端标识。

还可以通过 **“查看其他在线设备”**，读取同一在线账号下平台可见的设备记录。设备较多时支持继续加载。

这些信息以学校平台实际返回为准；未提供的字段不会猜测，历史信息会标明读取时间。设备列表提供查看功能，不包含强制下线操作。

## 开启监测，减少反复手动检查

需要持续关注连接状态时，可以开启后台监测，并按使用习惯调整检测间隔。默认间隔为 **1 秒**，最低可设置为 **0.3 秒**；实际检测节奏会受请求耗时、手机休眠和系统后台限制影响。

应用内提供小米、Redmi、iQOO、vivo、OPPO 等品牌的后台设置引导，帮助你查找自启动、电池优化和后台活动设置。需要后台监测时，应按提示允许通知并检查系统设置。

应用也设有认证失败保护：10 分钟内出现三次服务器明确拒绝后，会暂停自动认证，等待你检查原因。恢复记录和本地诊断日志，则能帮助你了解最近发生过什么。

## 免费开源，密码在本机加密保存

OUNet 没有广告、遥测或自建后台，账号与记录保存在本机，密码通过 Android Keystore 加密保护。

执行校园网认证时，必要的凭据通过 HTTPS 发往学校认证平台；联网检测和更新检查会访问相应的外部服务，但不会附带校园网账号和密码。

源码公开，你可以查看实现，也可以提出问题、反馈使用体验。

## 如何获取与开始使用

版本公开后，可前往 [OUNet GitHub Releases 下载页](https://github.com/JieShenAI/OUNet/releases)，选择 Android 正式版本的 APK。本文对应的准备版本为 **1.3.5**，安装文件名为 `OUNet-1.3.5-release.apk`，实际可用版本以下载页为准。

开始使用只需几步：

1. 在手机系统设置中连接校园 Wi-Fi。
2. 安装并打开 OUNet，添加自己的校园网账号和密码。
3. 选择认证账号，查看检测结果，或点击“重新检测并连接”。
4. 如果需要后台监测，再根据应用提示检查通知与后台权限。

已有正式版时，按发布说明使用同签名新版覆盖安装，无需先卸载。应用内也提供手动检查更新入口，下载与安装由你确认。

OUNet 负责检测与校园网认证，Wi-Fi 的选择和连接由手机系统管理。

**把找认证入口、重复输入密码的步骤交给工具，把注意力留给正在做的事。** 如果身边也有使用海大校园网的同学，欢迎把这款小工具分享给他们。
