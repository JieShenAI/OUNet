# OUNet Android 1.3.3

- XHA明确返回密码错误时，在连接概览持续显示红色“密码错误”提示，并提供“修改密码”入口。
- XHA仅说明账号或密码不正确时，显示“账号或密码错误”；账号不存在、网络异常、验证码错误等不一律归为密码错误。
- 明确凭据错误后立即结束当前认证，不再下载整条配置链复检；同一组错误凭据后续自动检测不再发送XHA请求或重复提交密码。
- 错误提示按本地账号和加密凭据指纹保存，重启或改备注后仍可见；更换实际密码后不继续显示旧错误。手动“重新检测并连接”可清除提示并重新尝试，确认成功后清除提示。
- 原包名、正式签名、账号密码加密、现有界面风格及底部免费说明保持。
