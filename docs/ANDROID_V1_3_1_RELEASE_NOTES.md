# 海大网络助手 Android 1.3.1

- 修复校园网识别：XHA返回可用的账号、密码输入框即视为校园网，不要求先登录，也不再要求表单页面包含特定脚本和样式文件；继续兼容脚本动态生成表单的现有XHA页面。
- 取消XHA每分钟请求配额、公共探测每服务每分钟配额及15秒等待，取消探测失败后30–120秒的退避。
- XHA识别失败仅短暂缓存300毫秒，按设置的节拍重新检测；手动连接立即重查失败结果。公共探测仅合并300毫秒内的重复请求，三个服务轮换。
- 启动、切换账号和手动连接主动复检网络；登录后及时复检，不再被之前探测失败的配额阻塞。稳定在线仍约15秒探测一次。
- XHA本次进程累计、最近60秒请求计数继续统计，包含失败请求。
- 保留账号密码加密、HTTPS校验、实际Wi-Fi绑定、原正式签名与账号设置。提交密码仍遵守至少60秒间隔及10分钟三轮失败保护，保护期间仍可检测网络。
