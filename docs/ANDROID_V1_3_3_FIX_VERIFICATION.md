# Android 1.3.3 密码错误提示实施与验证

日期：2026-10-23。版本1.3.3 / versionCode 7，包名`cn.jieshen.oucautologin`。对应[发布说明](ANDROID_V1_3_3_RELEASE_NOTES.md)。

## 实现

- XHA明确拒绝并说明密码错误时，连接概览显示红色提示与“修改密码”入口，直接打开当前账号编辑页；账号名沿用原来的只读规则。
- XHA说“账号或密码错误”时如实提示，并提供账号管理入口；明确账号不存在时单独提示。不根据未验证的数字错误码猜测密码错误。
- 仅在明确拒绝的响应中识别原因，按原始消息判断类别，再生成不包含账号密码的安全提示。避免脱敏替换误删password等关键词造成漏判。
- 已确认错误后立即结束本轮，不再重读完整配置链复检；后续同一组凭据的自动轮次在发出HTTP前结束。
- 本地仅保存错误类别、账号ID和加密密文/IV的SHA-256指纹，不增加密码明文或原始响应存储。重启、改备注、调整间隔保留提示；另一账号或真正更新的密码不套用旧提示。
- 手动重新连接/重置失败保护时清除提示并允许新尝试；确认成功后清除提示。无固定60秒认证冷却。

本版针对明确凭据错误处理提示和重复请求。未知状态、通用拒绝、已存在的通用三次失败暂停等路径未全面重构；旧版本只有“三次失败”记录而无具体服务器原因时，不凭空补出“密码错误”。

## 验证范围

新增回归覆盖中文/英文密码错误、账号或密码不明、账号不存在，以及超时、验证码、密码过期、欠费和未知错误不能误判；覆盖错误消息脱敏、存储跨重启、改备注/间隔、换账号、实际密码修改、旧轮不能写入新账号、手动重试成功后清除。

生产调用链模拟确认：首次密码错误共6次XHA请求（根页1次、前置状态4次、登录1次），后续20轮自动检测没有新增请求或重复登录。不是对真实学校服务发起的压力测试。

原生布局测试确认：红色提示持续可见，导航返回后保留，点击“修改密码”进入编辑页。截图为合成账号和模拟数据，不是真机校园网实测。

最终构建数据和截图归档见下方交付结果。真实校园网错误响应、各品牌后台及手机覆盖安装仍需实际设备验证。
