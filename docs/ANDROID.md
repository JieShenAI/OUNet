## 安装与启动

从android/dist取得正式APK并在手机确认安装。已有旧正式版时直接覆盖，不要先卸载；新版沿用原包名、正式签名与Keystore别名。真实覆盖升级仍需在设备验收。

打开APP即检测实际Wi-Fi的外网连通性，通过后显示“已联网”并结束本轮，不发送XHA请求。未读取过账号信息时提供主动刷新入口；已读取的信息保留并显示读取时间，不因缓存到期自动刷新。外网失败后检查XHA，返回可用账号、密码输入框即判为校园网，不要求先登录；同时兼容脚本生成表单的现有页面。读取XHA状态后，明确未登录且有选中账号时立即认证，不要求先打开后台监测。XHA已登录但外网异常不会重复提交密码。状态读取失败不冒充未登录；详情失败不撤销已确认身份。外网不可用且XHA不可达时显示红色“非校园网”并说明原因；仅外网通过不声称已核实校园身份。

顶部Wi-Fi名称只读；网络连接由系统管理，APP不扫描或切换。前台名称读取需要精确位置及系统定位；缺权限显示“没有网络或位置权限”，定位关闭、Wi-Fi关闭及系统隐藏名称分别说明。只缺名称读取位置权限且能唯一确认实际Network时仍可检测和认证。不申请后台位置。

## 账号、连接与设备

在连接概览的“认证使用账号→管理”新增、编辑或删除账号。密码不回填，空密码编辑只保留该账号原密码。切换账号立即检查外网，外网通过不查询XHA或强制下线；不可用时才读取XHA并按需认证。上方账号信息以XHA上次实际读取为准，手动刷新后更新。

点击“重新检测并连接”会先清除失败保护，强制请求XHA刷新状态和账号信息；确认未登录时立即使用选中账号认证，成功后重新读取六字段。连续点击合并为同一操作，每次操作只重置一次。没有Wi-Fi时也会完成本地重置；有存储错误时明确提示。

XHA明确说明密码错误时，连接概览显示红色“密码错误”和“修改密码”按钮；账号或密码不能区分时显示“账号或密码错误”和检查入口。错误按本地账号及加密凭据指纹保存，重启、改备注和调整间隔后仍可见，不把它显示在另一账号上。确认错误后停止这组凭据的自动XHA请求，修改实际密码后提示失效；修改后可点击主连接按钮立即再试。普通超时、验证码、欠费、模糊拒绝等不推断为密码错误。

XHA在线后显示账号、上线时间、源IPv4、源IPv6、源MAC、移动端标识。学校没有提供的字段不推测，详情失败时保留已确认身份并说明；旧信息标明上次读取。点击“查看其他在线设备”读取同一在线账号的设备；分页未完成时会说明，可加载更多或刷新，不提供强制下线操作。

## 监测与恢复

默认1秒、最小0.3秒，设置可输入最多三位小数。每轮先轮换Microsoft、Apple、Mozilla服务验证外网，连续临时故障使用自动复检冷却；仅合并300毫秒内的公共探测。外网优先探测不复用15秒在线缓存，下一节拍即可发现断网。没有系统认证页证据时单个探测失败先换服务复核。XHA识别失败最短300毫秒后可重查，手动连接立即重查。请求耗时、休眠和后台限制会影响实际时间。

连续三次临时故障后进入自动复检：15秒、30秒、1分钟、2分钟、5分钟，达到上限后继续每5分钟复检。XHA连通性与登录结果分别计数，认证超时或无法确认结果也会降低重试频率。每次先确认状态，仅明确未登录才提交一次认证，成功后恢复正常守护；取消、配置和详情读取失败不计为登录故障。

没有网络事件也会定时复检。网络恢复事件可提前复检一次，重复事件至少间隔15秒；用户关闭监测后不会自动认证。冷却进度跨重启保留，旧版三次失败暂停转为首轮15秒冷却。明确账号密码错误仍等待修改或用户主动操作；外网恢复只清临时故障，不抹掉密码错误记录。

诊断记录最新在顶部，打开期间独立约1秒检查新日志，不受用户检测间隔影响；查看历史时保留位置，关闭或退出前台后停止更新。日志按实际追加顺序显示，不按日期字符串排序。

恢复记录按故障去重，认证后稳定复检才计协助恢复，自行复通单列。底部显示本次进程与最近60秒的XHA请求尝试，含失败；缓存、未派发任务、公共探测、GitHub和外部浏览器请求不计。进程结束后重新统计，返回前台或旋转不清零。

## 权限与品牌后台

小米/Redmi、iQOO、vivo、OPPO的引导放在设置中。需要后台监测时允许通知，按系统实际菜单检查自启动、电池优化与后台活动。打开设置页不代表已经配置成功；应用不能自动证明厂商白名单状态，锁屏行为需真机测试。

## 版权、数据与更新

设置中有随APK离线提供的APP介绍、数据使用说明、版权与第三方声明。账号与记录本地保存，密码Keystore加密；本APP没有自建后台、广告或遥测。认证必需的凭据经HTTPS发给XHA，公共探测与GitHub更新会向对应服务发送请求及来源IP，不夹带校园账号和密码。

设置“检查更新”只读取固定仓库的Android正式Release元数据，显示版本并打开浏览器下载；用户通过系统确认覆盖安装。不会静默安装，不需要给APP授予安装未知应用权限。发布者须上传android-update.json附件；Windows Release、debug包或错误签名元数据会被排除。

## 本机构建

需要JDK 17/21、Android SDK 35和build-tools 35.0.0。本机可复用.toolchain中的工具；脚本设置本项目独立的Gradle缓存。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File android/build.ps1
```

默认执行JUnit/Robolectric、Lint与正式签名构建，输出APK、SHA-256、android-update.json和发布说明。正式签名核验不一致会停止生成更新元数据。私有密钥及keystore.properties只保留本机，必须私下备份；不要提交或重新生成来冒充更新。

源码和构建附件可按[交付记录](ANDROID_V1_3_IMPLEMENTATION.md)发布GitHub。构建成功不代表真实校园认证、品牌后台或手机覆盖升级已完成。
