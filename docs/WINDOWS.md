# OUNet Windows 0.3.5 使用说明

0.3.5 默认保留上一次校园账号信息，并包含自动复检、账号输入和按钮闪烁修复，详见[发布说明](WINDOWS_V0_3_5_RELEASE_NOTES.md)和[验证记录](WINDOWS_V0_3_5_VERIFICATION.md)。

## 安装与升级

[下载本地安装包](../desktop/dist/OUNet-0.3.5-Setup-x64.exe)。默认按当前用户安装，不需要 Python。安装包未代码签名，同目录提供 SHA-256。先从托盘退出旧版，再运行安装器覆盖安装；账号和设置保留，原临时失败暂停迁移为15秒自动复检，旧入口安全暂停仍需处理。免安装需完整保留 `desktop/dist/OUNet/`，不能单独复制 EXE。

帮助与关于提供作者邮箱 `shencv@163.com`、系统邮件、完整源码地址和 GitHub 下载页；均可复制。公开发布与待验收范围见[更新实施记录](RELEASE_UPDATE_VERIFICATION.md)。

## 首次使用

1. 先在 Windows 网络设置中连接校园 Wi-Fi 或可确认的 IPv4 网络。OUNet 只读显示当前连接，不扫描、不选择或主动切换 Wi-Fi。
2. 打开“账号管理”，添加账号与密码，确认没有其他自动认证入口，再保存。已保存密码由 Windows 当前用户 DPAPI 加密，不能直接搬到另一台电脑使用。
3. 在概览选择“下次认证使用账号”。开启自动监测安排后续检查；也可以随时主动“重新检测并连接”。
4. 有旧 `.env` 或计划任务时，从“偏好设置”导入并核对旧入口。只有完成接管后才允许自动认证。

每次启动即检查一次，即使自动监测关闭；临时故障暂停先等待复检时间，旧入口或本地数据异常不自动放行。Wi-Fi 名称不可见时会按可确认接口检测；接口归属不明确时不给出已认证结论，也不提交凭据。

## 连接、身份与操作

- **自动监测**：先验证外网，通过后立即结束，不读取 XHA、不提交密码。已有上次账号信息时继续显示；首次使用没有记录时显示中性占位，可主动刷新。
- **刷新信息**：主动只读查询 XHA，更新真实在线账号、上线时间、源 IPv4 / IPv6 / MAC 和移动端标识；永不提交密码、不清空保护。
- **重新检测并连接**：主动识别 XHA 并读取登录态。明确未登录时最多提交一次选中账号的认证；已在线时不重复登录。认证成功后验证外网并按需更新身份。
- **查看在线设备**：查询 XHA 当前实际在线账号可见的记录，只读展示。分页未完成会明确说明，按需加载更多，不提供强制下线。

本地选用账号与网站在线身份分开。切换本地账号不注销现有会话，联网时不强制换号。旧快照直接显示账号和六项信息，标注上次读取及原读取时间，无需展开。刷新未登录或失败不会清空旧信息，不将其当成当前登录身份。字段缺失不推测。

## 账号与密码错误

编辑已保存账号时，密码输入真实值为空；`********` 仅为占位，留空保留旧密码。输入新密码后保存才会替换。备注与密码分别处理，删除本机账号不注销网站会话。删除当前选用账号后需重新明确选择，不会自动使用另一账号。

XHA 明确返回密码错误时持续显示“密码错误”；只能确认账号或密码错误时如实显示。该账号/凭据版本的自动 XHA 请求停止，外网探测仍可运行。改备注或保存同一密码不解除；实际更正密码、选用其他账号，或主动尝试一次可继续。外网可用不证明密码正确。

## 间隔与自动恢复

新用户默认 1 秒，支持 **0.3–2147483 秒**、最多三位小数；升级保留原间隔。每轮完成后再等设定时间，绝不并发补发。最近耗时长于间隔时会说明；没有固定 60/120 秒认证冷却。

XHA传输、认证结果、外网探测和GitHub更新分别记录临时失败，互不因无关服务的成功而清零。正常门户重定向不是传输失败；明确密码错误仍按账号和凭据版本独立停止。

**连续三次临时故障后暂时暂停，到期自动复检。** 等待依次为15秒、30秒、1分钟、2分钟、5分钟，达到上限后继续每5分钟复检。每次只允许一个串行恢复流程，先检查外网及XHA状态，仅在确认未登录时认证；成功后继续正常守护。取消、接口变化不作为认证拒绝。

网络重新连接可提前复检一次，重复事件至少间隔15秒。即使没有网络事件，也保留定时复检。重启保留冷却进度；升级前普通三次失败暂停转为首轮15秒冷却。用户关闭自动监测后不安排自动认证；本地数据异常和旧入口安全暂停仍需人工处理。

“手动重试”可提前复检，但不会自动清除已确认的密码错误。后台检测与冷却倒计时不锁定账号编辑器。

## 恢复与诊断

概览恢复明细按本次电脑开机统计。软件参与认证、观察到故障且同连接稳定复检通过后计一次；自行复通、重复检测、打开软件时已经联网不增加。重开软件保留，新的开机范围重新统计；无法识别开机范围时明确提示。

XHA 请求统计按**本次进程**和最近 60 秒显示，每次实际派发的校园请求含失败各计一次。公共探测、GitHub、缓存和未派发任务不计；“请求尝试”不代表服务器实际收到。

帮助页诊断最新在前；打开期间只检查本地日志变化，不受检测间隔影响。看历史时保留位置，提示有新记录。可筛选记录或导出脱敏文件；软件不会在日志中保存密码、完整认证 URL 或原始响应。

## 托盘、更新与数据

关闭窗口可留在托盘，完全停止请使用退出。登录后自启由用户选择。睡眠时不补发积压请求；真实睡眠、锁屏和重启行为仍需环境验收。

帮助页手动检查此仓库的 Windows 正式发布，排除 Android APK、草稿和预发布；显示版本、来源、SHA-256 后由用户使用浏览器下载和安装。没有有效元数据时只说明原因，不提供猜测链接，不静默执行安装器。

数据保存在 `%LOCALAPPDATA%\OUCNetworkAssistant\`：

| 文件 | 内容 |
| --- | --- |
| `settings.json` | v3 设置、毫秒间隔、活动账号 ID、外观与偏好；旧 SSID/profile 仅兼容保留 |
| `credentials.dat` | 当前用户 DPAPI 多账号密文、备注与凭据版本 |
| `request-state.json`、`request-state-*.json` | XHA传输冷却、旧入口安全暂停与独立凭据错误 |
| `portal-snapshot.dat` | 加密会话快照与连接归属 |
| `recoveries.json` | 开机、故障、连接与恢复明细 |
| `configuration.pending.json` | 事务中断标记；存在时停止认证 |
| `logs/activity.jsonl` | 最多 300 条本地诊断记录与追加顺序 |

没有自建云账号、广告或遥测。Windows 更新查询和公共探测仅请求各自服务。真实校园登录、不同网络/权限、覆盖安装、DPI 与辅助技术的完整验收范围见 [v0.3 验证记录](WINDOWS_V0_3_VERIFICATION.md)。
