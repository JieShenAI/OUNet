# Windows 0.3.5 上次账号信息显示验证

日期：2026-10-24。

## 修复

旧界面将过期、接口变化或离线状态的会话字段隐藏，只有展开历史后才显示，导致明明有旧账号仍出现“校园身份尚未读取”。未登录的刷新结果还会覆盖持久化账号快照。

本版只要有上次读取的账号，就直接显示账号与六项信息，保留读取时间并标注为上次读取。取消历史展开按钮与“尚未读取”提示。没有任何历史记录时使用中性占位，不以本地选用账号冒充XHA身份。

没有账号身份的刷新结果不覆盖旧快照，不更改旧记录的网络归属、时间和字段；成功读取有账号的新结果才替换并保存。设备信息仍按原连接/身份规则失效，不用旧账号快照授权设备操作。

## 验证

- 123项桌面单元测试通过，覆盖未登录刷新后六字段及持久化快照保留、重启仍读到旧记录，以及新身份成功后替换快照。
- 真实QML检查：模拟接口变化与过期会话，直接核对账号和六项文字；清空历史记录后显示中性占位；原输入法、按钮与自动复检检查继续执行，无QML警告。
- 构建脚本执行47项CLI/发布工具测试、源码QML、独立EXE环境检查、安装器和完整ZIP打包。日志位于本地`desktop/build-session-history.log`及`desktop/screenshots/v0.3-ui/ui-report.json`。

自动检查使用隔离数据与模拟网络，未覆盖用户现有安装或执行真实校园认证。本次仅更新Windows，Android 1.3.6保持原构建。
