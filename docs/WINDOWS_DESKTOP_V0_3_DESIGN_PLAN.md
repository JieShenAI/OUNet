## 1. 产品方向

把 OUNet 做成一个安静、可信、可以长期留在托盘的校园网络助手。用户打开窗口，首先看懂当前连接、真实在线身份、是否需要自己处理；遇到问题时，有清楚且可执行的下一步。

手机端提供成熟的连接与错误处理逻辑；桌面端用固定侧栏、并排工作区、可复制的数据、抽屉和键盘操作承载更多信息。正常状态减少文字噪声，异常状态说明原因和下一步，不依靠反复跳出的提示。

成功标准：熟悉电脑的普通用户在约 5 秒内找到连接状态和主要操作；日常无需打开窗口；密码错误能直接定位到对应账号；请求统计能解释软件是否在重复访问 XHA。这些是待可用性验证的目标，不是已测得指标。

### 1.1 来源与优先顺序

1. 本轮要求：参考手机功能，优化 Windows 界面和程序逻辑，先交付设计与规划。
2. [手机端对话](codex://threads/01a1637b-d737-7bd3-a097-2faff7900e17)：以最新 1.3.4 行为为准，不能照搬早期 1.3 方案的缓存、冷却和配额。
3. [桌面端对话](codex://threads/01a163ce-773f-76c1-a769-6902d92622a2)：保留明确确认的实际请求三连败、开机恢复范围、不设连接记录页等要求。
4. 当前源码和验证记录用于确认现状；界面提案和未来功能在本文明确标记。

冲突处理：手机端“10 分钟内三次明确认证拒绝”和桌面端“实际 HTTP 连续三次失败”不是同一规则。本方案保留已经确认的桌面规则，不因跨端统一而重新引入十分钟窗口。手机主按钮无条件清空保护的行为也不覆盖桌面的一次试探机制。

### 1.2 跨端功能取舍

| 手机端能力 | 桌面端决定 | 原因 / 落地方式 |
| --- | --- | --- |
| 外网通过后不自动访问 XHA | 采用 | 普通启动、周期、网络变化、账号切换都走外网优先；会话缓存过期不触发查询 |
| 当前 Wi-Fi 只读，不扫描切换 | 采用，并适配 Windows | 展示实际连接和网卡；从应用内选 Wi-Fi 改为“打开 Windows 网络设置” |
| 多账号与加密密码 | 保留并改善 | 概览快速选择，账号页管理；DPAPI 当前用户加密 |
| 当前会话六字段 | 保留 | 独立显示读取时间、连接归属和旧快照；本地账号选择不冒充在线身份 |
| 明确密码错误后停止重复提交 | 采用 | 绑定账号及凭据版本；提供修改密码入口 |
| 其他在线设备 | 新增，只读 | 从会话卡打开右侧抽屉；按 XHA 实际在线账号查询 |
| 秒级 / 小数间隔 | 采用 | 新用户默认 1 秒、最低 0.3 秒，毫秒整数存储；旧用户保留原值 |
| 手机三次认证拒绝保护 | 不移植这套计数 | 桌面保留全局实际请求三连败；另加凭据错误阻断 |
| 恢复记录独立导航 | 不移植导航 | 恢复明细留在概览，符合既有桌面要求 |
| XHA 调用统计 | 新增 | 概览恢复明细下方，区分进程与滚动 60 秒；与开机恢复次数分开 |
| 诊断最新置顶、自动更新 | 采用 | 帮助页进入可调整宽度的诊断抽屉 |
| APK 权限、厂商后台说明 | 换成 Windows 机制 | 定位 / WLAN、登录后自启、托盘、睡眠唤醒和多网卡 |
| 离线说明与更新 | 采用结构 | 帮助页离线说明；Windows 更新按 Windows 元数据单独实现 |

## 2. 当前问题与设计回应

| 当前证据 | 用户影响 | 本版设计 |
| --- | --- | --- |
| `qml/Main.qml`：深色侧栏、学校标识和多层说明文字 | 品牌重心分散，窗口显得沉重 | 浅色侧栏 + OUNet 新图标；移除学校徽标和校园背景图 |
| `engine.py`：认证前必须匹配配置 SSID | 切网后软件依赖旧目标名称，不符合手机现有逻辑 | 当前真实连接作为上下文，取消目标 SSID / profile 的产品入口 |
| `controller.py`：`refreshSession()` 与普通检查共用 `_check()` | 按钮意图不够明确 | 拆分普通检查、主动重连、只读身份、设备分页四类意图 |
| `portal_status.py`：`fetch_session()` 将多种结果归为不可用 | 详情失败可能与未登录混淆 | 分开在线 / 未登录 / 未知；详情失败独立表示 |
| `request_policy.py`：全局实际 HTTP 三连败 | 与手机计数不同，不能照搬 UI 文案 | 明确“自动网络请求已暂停”；所有自动路径统一受门禁约束 |
| 拒绝账号只存账号 ID，错误判断依赖宽泛文字 | 改密码、误判、重启后的错误语义不清 | 结构化错误 + 账号/凭据版本绑定；不凭模糊“密码”字样下结论 |
| 恢复台账已有开机范围，但缺少请求量解释 | 无法区分修复次数和请求次数 | 保留开机范围；增加清楚标注的进程请求计数 |

上述结论来自本地代码阅读；未为本次设计调用真实门户或提交账号密码。

## 3. 信息架构与页面职责

固定四个主入口：**连接概览、账号管理、偏好设置、帮助与关于**。原“账号与网络”改为“账号管理”，当前网络置于全局只读栏。路由使用名称，不使用数字页码。

```text
OUNet 窗口
├─ 全局：应用标题栏 / 当前连接 / 异常通知 / 底部运行状态
├─ 连接概览
│  ├─ 当前校园会话：六字段 / 来源 / 读取时间 / 刷新
│  │  └─ 在线设备抽屉：本机、其他设备、分页
│  ├─ 自动监测 / 下次认证使用账号 / 重新检测并连接
│  ├─ 本次开机恢复次数与时间线 / 展开全部
│  └─ XHA 调用统计：本次进程 / 最近 60 秒
├─ 账号管理
│  ├─ 保存的账号列表 / 选用 / 添加
│  └─ 编辑详情：账号、备注、密码状态、修改、删除
├─ 偏好设置
│  ├─ 检测间隔 / 自动监测 / 登录后自启 / 关闭到托盘
│  └─ 通知 / 外观 / 网络读取说明 / 旧入口迁移
└─ 帮助与关于
   ├─ 诊断抽屉 / 导出脱敏信息
   ├─ 离线介绍 / 数据使用 / 版权与第三方许可
   └─ 当前版本 / 手动检查 Windows 更新
```

恢复时间线可展开或分页，仍属于概览，不增加侧栏“连接记录”。“在线设备”和“诊断”是上下文内容，不增加常驻导航。切换主页面前关闭抽屉，焦点返回入口或新页面标题。

## 4. 桌面视觉规范

### 4.1 风格与品牌

方向：**轻、清楚、有秩序的海洋蓝工具界面**。保留 OUNet 的开口 O 与海浪品牌图标，蓝色集中用于选中态、主要操作和关键链接；青色作为细节。避免大幅背景照片、整屏深蓝和装饰性仪表盘。

使用现有 [OUNet 品牌素材](../design/ounet/README.md)。产品标题只写 OUNet；副标题“校园网络助手”。帮助页保留“独立开发，非学校官方软件”和“免费软件，供学习交流与使用”。不重新生成 Logo。

## 5. 页面设计与关键交互

### 5.1 连接概览

顶栏显示“当前连接：OUC-Campus-Demo · Wi-Fi”，没有下拉箭头；多网卡不可确认时显示“正在确认当前连接”。旁边“网络设置”打开 Windows 对应系统页面。SSID 无法读取时显示具体原因；能确认接口时不因名称不可见而一律阻止认证。

主区左侧从上到下：会话卡 → 开机恢复时间线 → XHA 调用统计；右侧为监测与认证操作区。窄窗口按“会话 → 操作 → 恢复 → 统计”的顺序阅读。全局暂停或密码错误的横幅放在会话卡上方。

会话卡：

- 卡头“校园网会话”与小状态标记，六字段保持视觉主体：账号、上线时间、源 IPv4、源 IPv6、源 MAC、移动端标识。
- 已联网但未查询身份：显示“外网可用 · 校园身份尚未读取”，字段显示“尚未读取”，提供“刷新信息”。不为了填满首页自动请求 XHA。
- 同连接已有快照：标“上次读取 12:20:08”，不得标“刚刚更新”；外网每秒检测不改变读取时间。
- 原始 `phone_flag` 缺失显示“页面未提供”；存在时按已核实映射显示“PC 端（0）/移动端（1）”，未知值保留原值并说明未知。
- 字段可选择复制，按钮提供复制反馈；字段值和服务端文本以纯文本显示，不执行 HTML 或脚本。
- “刷新信息”只读查询，不重置保护、不提交密码；“查看在线设备”按当前 XHA 身份查询。

操作区：

- “自动监测”开关独立控制后续周期；关闭后仍可手动操作，打开不清空保护。
- 清楚显示“每轮结束后等待 1 秒”、上次检测时间、最近耗时。短间隔提示紧邻设置摘要，不占用永久告警位。
- “下次认证使用账号”下拉与“当前在线账号”并存。两者不同时显示一行说明：“当前在线 demo_2026001；下次认证使用 demo_2026002”。
- 唯一主按钮“重新检测并连接”。进行中按阶段显示“正在读取登录状态 / 正在认证 / 正在验证外网”，阻止重复点击，不累计点击次数。
- 账号密码错误横幅提供“修改密码”；全局暂停横幅提供“手动重试”。两个问题同时存在时，先提示全局暂停，凭据错误仍在账号位置显示。

恢复区默认显示最近三条，包含时间、方式、耗时；“展开全部”在概览内展开。无记录时写“本次开机尚无助手参与并验证成功的恢复”。显示开机起点；无法可靠识别启动范围时显示“开机范围待确认”，不悄悄改成进程统计。

### 5.2 账号管理

宽屏左侧账号列表，右侧编辑详情；窄屏变为列表后进入详情并可返回。顶部“添加账号”。列表显示备注、脱敏账号、密码已保存 / 需修改标记和当前选用状态。

新增需要真实账号与非空密码；编辑已有账号时实际密码值为空，固定 `********` 仅为占位，附“留空保留已存密码”。明确点击“修改密码”后输入新值。新值不能用星号占位推导。默认不回显已存密码；用户刚输入的密码可用显隐按钮检查。

保存成功提示“账号已保存”，选择操作单独表示“用于下次认证”；不会声称已经登录。有未保存修改时，切账号提供保存 / 放弃 / 取消。删除只删除本地账号与对应密文，二次确认且说明不注销线上会话。删除当前选中账号后清空选择，要求用户重新选择，不静默换号认证。

### 5.3 偏好设置

按“连接、Windows 行为、外观与通知、兼容与迁移”分组。开关即时写入，失败则回滚并显示原因；间隔采用输入 + “应用”，避免每输入一个数字就重排网络任务。

新用户默认 1 秒，预设 0.3 / 1 / 3 / 10，自定义 0.3–2147483 秒，最多三位小数，存储 `interval_ms`。旧值按秒 × 1000 迁移，不改成 1 秒。保留旧上限兼容现有设置；调度接近 Qt 定时器范围时采用分段等待。

文案：“每轮完成后再等待设定时间；耗时较长时实际检测间隔会更长。”如上一轮耗时 2.4 秒、设置 0.3 秒，提示“间隔短于本轮耗时；不会并发补发”。输入非法值保留上次有效设置；不四舍五入接受超范围值。

保留：登录 Windows 后启动、关闭到托盘、重要通知；新增：跟随系统 / 浅色 / 深色。首次设置只介绍账号与监测，不再要求选择 Wi-Fi。发现旧 CLI 时保留现有精确迁移流程，用户取消后不接管认证。

### 5.4 帮助与关于

第一组是解决问题：打开诊断、导出脱敏记录、网络读取说明。第二组是离线介绍、数据使用、版权与第三方许可。第三组是本机版本与“检查更新”。免费说明与独立开发身份明确但不过度占据页面。

Windows 更新仅用户点击时查询 Windows 正式版本元数据，不复用 Android 的 APK 元数据。展示版本、说明、下载来源，由用户打开浏览器下载安装器；不静默安装。固定仓库与 Windows 附件命名、签名/哈希校验需在实施时核实，未完成前隐藏可执行下载入口并解释。

### 5.5 在线设备与诊断抽屉

在线设备：约 440 宽，显示实际在线账号、读取时间、本机标识和分页状态。无法唯一匹配本机时明确说明；不任取第一行。只有进入、刷新、加载更多时请求，不随 1 秒节拍刷新。分页失败写“已读取 N 条，尚未全部读取”；账号/接口上下文改变，立即失效。只读，无强制下线。

诊断：约 520 宽，最新置顶。记录本地追加序号、时间、操作来源、阶段、结果；打开期间每秒检查本地日志版本，有新内容才更新，关闭停止。用户读历史时保持锚点，提示“有新记录”，点击后回到顶部；不自动把用户拉走。过滤可区分普通检测 / XHA / 错误，导出前预览脱敏范围。

浮层支持 Esc、明确关闭、焦点限制和焦点归还；小窗口全宽展示，不让抽屉挤压主区成不可读窄条。

## 6. 连接与请求逻辑契约

### 6.1 先拆开四类状态

| 状态维度 | 值示例 | 不能据此推导 |
| --- | --- | --- |
| 外网连通性 | 未确认 / 检测中 / 可用 / 验证失败 | 外网可用不证明 XHA 在线身份 |
| 校园服务 | 尚未访问 / 可识别 / 不可达 / 格式未知 | XHA 超时不能证明网络地理归属 |
| XHA 登录态 | 在线 / 未登录 / 未知 | 详情缺失、无 uid 的异常响应不等于未登录 |
| 运行与门禁 | 自动开启/关闭、忙碌、全局暂停、凭据阻断 | 关监测不注销会话，开监测不解除暂停 |

界面组合上述维度，不用一个 `online` 布尔值代表全部事实。“非校园网”只作为 XHA 不可达场景的产品标签，旁边固定说明“当前连接无法访问校园认证服务，尚未提交账号信息”；普通超时不给出网络归属保证。有已知本连接校园证据时写“校园服务暂不可用”，避免互相矛盾。

### 6.2 自动流程

```text
启动 / 周期到时 / 唤醒 / 网络变化 / 选用账号
  → 检查全局暂停：暂停则不派发任何自动 HTTP
  → 获取当前连接上下文和操作代号
  → 探测该连接的外网
      ├─ 通过：结束；不读取 XHA、不认证、不按缓存到期刷新
      ├─ 单源失败：换一个独立源复核；连接变化则丢弃结果
      └─ 外网未通过验证
          → 当前凭据已明确错误：不发送自动 XHA，展示修改入口
          → 识别 XHA，读取真实登录状态
              ├─ 在线：不重复登录；外网异常单独展示
              ├─ 未登录：有账号且准入允许 → 本轮最多认证一次
              └─ 未知：说明原因；不凭详情读取失败猜测未登录
          → 认证成功后复检外网；确认恢复再登记事件
```

启动即检测不依赖监测开关。全局已暂停时启动只读取本地状态并显示暂停，不以“启动检测”为名绕过。WLAN 枚举、系统启动标识、迁移任务扫描和更新检查不得挡住可执行的首轮检测。

严格遵守手机最新要求：自动流程一旦验证外网通过就结束，不在其后附加 XHA 会话读取。认证本身已返回的身份字段可以展示；未取得的六字段显示未读取，由用户主动刷新。此决定覆盖旧 Windows “首次启动 / 恢复后自动读全六字段”的要求；数据真实性与请求透明度优先，不伪造自动填充。

### 6.3 三类主动操作

| 操作 | 会访问 XHA | 会提交密码 | 保护行为 |
| --- | --- | --- | --- |
| 刷新信息 | 是，强制更新当前会话 | 永不 | 不重置任何保护；全局暂停时引导手动重试 |
| 查看在线设备 / 加载更多 | 是，按当前真实在线 uid 读取 | 永不 | 不绕过全局门禁；进入时说明请求来源 |
| 重新检测并连接 | 是，强制识别与查询登录态 | 仅明确未登录时，本轮最多一次 | 允许对选中凭据做本次手动重试；不无条件重置全局保护 |

全局暂停时主按钮改为“手动重试”：保留 Windows 已确认的一次请求试探语义，先放行一个实际 XHA 只读请求；校验成功后清零全局连续失败并继续本次主动流程，失败则立即保持暂停。成功 HTTP 不代表密码有效，凭据错误标记不随之清除。试探没有派发成功不视为恢复；本地状态保存失败则停止。

### 6.4 两种保护必须独立

**全局实际请求保护**：沿用现有 Windows 口径。每个实际 HTTP 在完整读取与内容校验后只结算一次；超时、TLS、连接错误、无效响应记失败；成功请求清零。外网探测收到正常门户重定向等“需要认证”的有效结果不作为传输失败。取消且尚未派发的任务不计数。第三次失败立即阻止本轮剩余请求和后续全部自动 HTTP，包括公共探测、XHA、设备分页；用户手动检查更新也不绕过统一网络门禁。

正常状态不显示永久“失败保护待命中”卡。失败一次或两次显示最近原因；第三次才出现“连续 3 次网络请求失败，自动请求已暂停”。系统网络事件只能更新本地连接信息和提示可重试，不能擅自解除暂停。开关监测、换账号、改间隔、重启都不清空全局暂停。

**凭据错误阻断**：XHA 明确表示密码错误就显示“密码错误”；仅明确账号或密码错误时如实显示组合文案；账号不存在、欠费、设备限制、超时和未知响应各自处理。绑定 `account_id + credential_revision`，不存可离线猜密码的普通哈希。该凭据阻断后自动外网检测仍可运行（全局未暂停时），自动 XHA 全链路不再请求；换备注不解除，实际保存新密码产生新版本，只解除该凭据的标记。选中别的账号不受这条标记影响，但仍受全局保护。

手动重连对被阻断凭据只授予本次操作一次认证机会；若再次明确错误立即重新阻断。外网自行恢复可以显示已联网，不能因此宣布密码已正确。普通探测 HTTP 成功也不清除密码错误。

不引入固定 60/120 秒认证冷却、十分钟窗口、每分钟认证配额或指数退避。串行、取消、超时和保护是明确的请求边界，不包装成隐藏等待。

### 6.5 调度与连接上下文

- 保留单工作执行器和完成后计时：`下一轮最早开始 = 本轮完成的单调时钟时间 + interval_ms`。没有补发队列；重复自动触发合并为一个待执行意图。
- 手动意图优先于尚未派发的自动意图；已经在途的请求不能撤回，先等结束 / 超时，再执行新操作；旧结果不得覆盖新账号或新连接。
- 门户、外网、设备与更新使用同一请求准入和串行派发层；更新低优先级，不自动后台轮询。有效响应才结算成功，读取/解析失败不能先成功后失败算两次。
- 建立 `operation_id / network_epoch / account_revision`；每个响应写回前检查。切换接口、地址变化、睡眠恢复、同 SSID 重连都更换网络代号。
- Windows 不照搬 Android `Network` API。实施先验证路由 / 源接口约束；只能在实际探测与认证使用同一可确认接口时自动认证。多网卡、VPN、代理导致归属不明确时说明原因，暂停凭据提交，不任取第一块无线网卡。
- 有线校园网纳入同一模型，但列为 P1：需先验证接口归属和实际门户行为。P0 无 Wi-Fi 时显示连接信息和打开系统设置入口，不回退旧 SSID 自动切网。
- 当前 HTTP 请求保持 TLS 校验、固定门户允许范围、无自动外域重定向。认证上下文仅在同连接同一流程中复用；跨接口和不确定地址变化必须重新识别，不能复用过期 IP。

### 6.6 快照与请求统计

六字段数据附 `fetched_at / network_epoch / online_uid / availability`。缺字段写“页面未提供”；只读请求失败不改变已确认的登录态。重连、换网或真实 uid 改变后清理关联设备数据。重启应用后无法证明磁盘快照仍属于当前连接时只展示折叠的“上次会话”，不标为当前身份。

XHA 调用统计口径：每次实际派发 XHA 页面、脚本、配置、状态、认证、设备分页各 +1，失败尝试也 +1。明确重试和允许的跳转逐个计数；缓存、本地读取、未派发、公共探测、GitHub 更新和外部浏览器不计入。字段命名“请求尝试”，不能说“服务器实际收到”。本次进程重启清零，返回前台不清零；滚动 60 秒按单调时钟，界面刷新不发 HTTP。

恢复统计继续按系统开机范围持久化，和上述请求统计的进程范围明确分开。

### 6.7 恢复入账

只有先观察到本连接外网故障、软件参与认证且随后同连接复检成功，才作为候选；约 2 秒后再通过一次稳定验证才计一次协助恢复。首次复检通过即可更新联网状态，稳定验证完成前不加次数。

同一故障以 `incident_id` 去重；详情读取成功、刷新页面、网络分类变化、打开软件时已联网都不加次数。自行复通记录为“网络自行恢复”，不加入协助恢复总数。新版本取消应用主动切 Wi-Fi 后不再生成“Wi-Fi 重连恢复”事件，历史事件按原方式保留。开机标识查询晚于恢复时可暂存候选，确认范围后再原子提交。

## 7. 桌面系统行为与无障碍

托盘显示在线 / 待确认 / 处理中 / 自动关闭 / 全局暂停五种图标与文字 tooltip。菜单含打开 OUNet、重新检测并连接 / 手动重试、自动监测开关、退出。托盘和主窗口使用同一命令与保护。关闭到托盘第一次给一次非打断提示；退出明确停止监测，窗口关闭不冒充退出。

通知只在新发生的密码错误、全局暂停或用户允许的恢复事件出现；按事件 ID 去重，不每秒重复通知。提示不含完整账号、密码和地址。锁屏、睡眠恢复不集中补发遗漏任务。

键盘：Tab 顺序按阅读顺序，按钮支持 Enter / Space；Esc 关浮层；Ctrl+1–4 切主页面；Ctrl+R 触发当前页只读刷新，不映射为提交密码；主动重连用明确按钮。焦点边框 2 逻辑像素，不在自动刷新时抢焦点。状态变化通过可访问文本播报，稳定状态不每秒播报；高对比模式优先系统色，关闭不必要动画。

默认交互动效 120–180ms，仅透明度或轻微位移；开启减少动画后直接切换。不做持续海浪动画、粒子或装饰性网络图。

## 11. 已做出的决定与待核实事项

已决定：四入口、浅色桌面工作区、保留开机恢复、取消目标 Wi-Fi 产品入口、自动在线不请求 XHA、两种保护独立、只读刷新不提交密码、保留现有 Windows 全局保护、新用户 1 秒 / 最低 0.3 秒、旧用户间隔不变。
