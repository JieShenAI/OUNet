## 下载与安装

普通用户下载 `OUNet-1.3.5-release.apk`。`ouc-autologin-1.3.5-release.apk` 是同一文件的兼容名称，供旧版更新入口使用，选择一个即可。

已有正式版请直接覆盖安装，无需先卸载；保留原包名、原正式签名和本地数据。版本号 1.3.5，versionCode 9。安装由 Android 系统确认，应用不会静默安装。

检查更新仅查询本仓库 Android 正式发布；草稿、预发布和 Windows 安装器不进入默认更新。浏览器下载失败时可复制 GitHub 下载页地址后重试。
