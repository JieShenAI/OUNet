# Android 1.3.2 实施与验证

日期：2026-10-23。版本1.3.2 / versionCode 6，包名`cn.jieshen.oucautologin`，Android 9起可用。对应[升级规划](ANDROID_V1_3_2_LOGIC_PLAN.md)与[发布说明](ANDROID_V1_3_2_RELEASE_NOTES.md)。

## 实现结果

| 需求 | 最终行为 |
| --- | --- |
| 取消认证冷却 | 删除连接层、存储层60秒判断与相应延迟分支；旧`last_auth_at`不再授权或阻止认证 |
| 主按钮重新连接 | 协调器建立独立用户操作，先撤销旧轮和延迟回调，重置失败保护，再实际请求XHA；连续点击合并 |
| 刷新账号信息 | 强制绕过校园正缓存、会话10秒门槛和5分钟详情缓存；当前操作内复用刚取得的协议上下文，减少重复请求 |
| 未登录立即登录 | XHA明确`result=0`时使用选中账号认证，不先等待公共探测；后台关闭也能执行本次按需连接 |
| 避免重复认证 | `result=1`为已在线，即使缺uid、详情失败或外网不通，也不重复提交密码；未知响应明确报告，不猜测未登录 |
| 认证后刷新 | 同一操作中重新查询XHA状态和六字段，再独立验证外网；已登录但外网异常显示对应说明 |
| 失败保护 | 仅XHA明确拒绝增加失败数；10分钟内3次明确失败暂停自动认证。成功/确认在线清零，主连接按钮立即清零后重试 |
| 旧数据迁移 | 第一次读取失败状态时原子归档旧预占次数与冷却记录，清除旧暂停，初始化新记录；不改变账号密文、Keystore、设置和恢复记录 |
| 诊断记录 | 最新记录置顶；显示期间独立每秒检查版本，有变化再更新；关闭/暂停停止；浏览历史保留文本锚点和阅读位置 |
| 权限提示 | 缺网络读取/精确位置权限显示“没有网络或位置权限”；定位关闭、Wi-Fi关闭、未连接及系统隐藏名称分类显示 |
| 仅缺位置权限 | 唯一实际Network可确认时仍能进行校园识别和认证，SSID不作为前置条件 |

启动、账号切换、自动检测与主按钮共用XHA状态决策。只有明确主按钮操作重置一次；复检、周期和网络变化不反复清空失败数。后台仍按用户设定节拍运行，无新的固定认证冷却或分钟请求配额。

XHA本进程与最近60秒请求计数、账号本地加密、原正式签名、实际Wi-Fi绑定、HTTPS验证、海大名称及底部免费学习交流说明继续保留。会话/设备身份变化会清除旧账号数据；后台复用有效详情时不取消用户正在进行的信息刷新。

## 自动验证

执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File android/build.ps1
```

最终完整构建：**126项测试，0失败、0错误、0跳过；Android Lint无问题；release构建通过。** 覆盖JUnit协议/策略测试及Robolectric Android 9/API28、Android 15/API35界面与存储测试。

关键回归：

- 三次明确拒绝可在不足一秒的连续操作中产生，证明不再有60秒门槛；第三次后自动暂停，主按钮立即解除并重新认证。
- 旧版有效/损坏预占记录、旧冷却字段一次归档；新失败状态损坏时停止请求，显式重置可恢复；写入失败不假装成功。
- 公网正常但XHA未登录仍认证；XHA已登录但外网失败、缺uid或详情503均不重复登录；未知状态不认证、不计密码失败。
- 强制重新连接在10秒内真实请求根页并更新不同在线账号；不会继续显示5分钟内的旧身份。
- 同时点击合并为一次重置；替换旧轮后旧结果不覆盖新轮；没有Wi-Fi仍完成本地重置。
- 网络权限拒绝不发请求、不残留“已联网”；仅拒绝位置仍可通过唯一实际Wi-Fi认证。
- 日志按追加顺序逆序，跨年/同秒/调时不乱序；打开后新增日志可见，关闭清理更新任务。
- 原有公共探测轮换、调用计量、恢复台账、分页、更新元数据、长IPv6、大字号和固定免费说明继续通过。

测试使用合成账号与模拟Network，没有提交真实校园账号。初轮测试暴露的模拟环境普通权限缺省未授予、异步弹窗关闭断言和旧迁移次数断言均已修正；测试明确模拟真实安装时的普通网络权限授予，并单独测试拒绝场景。
