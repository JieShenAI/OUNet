# OUNet Android 1.3.4

- 启动、账号切换和自动监测先验证实际Wi-Fi的外网连通性；验证通过立即结束，不请求XHA、不重复认证，也不因账号详情缓存到期而自动刷新XHA。
- 按设定间隔轮换Microsoft、Apple、Mozilla探测服务；外网优先检查不使用原有15秒在线缓存，避免缓存掩盖新断网。保留300毫秒内重复探测的合并。
- 外网不可用后按原规则识别XHA、读取状态及按需认证。没有系统认证页证据时，单个公共服务失败先换服务复核，避免一次失败立即触发认证。
- 已读取的账号及IP信息保留并显示读取时间；首次启动时若外网正常，不自动查询身份，可点“刷新”主动获取。切换Wi-Fi或配置后不沿用其他连接的身份信息。
- “重新检测并连接”仍按用户操作强制请求XHA、重置失败保护并在未登录时认证；“刷新”和“查看其他在线设备”也属于用户主动查询。
- 健康监测日志仅显示“外网验证通过”，不再循环出现读取XHA状态和确认账号的多条日志。外网自行恢复时可恢复联网显示，不重复提交已确认错误的凭据；再次断网时仍保留密码错误保护。
